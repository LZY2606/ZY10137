# 野外个体身份假设与捕获历史系统

一个 Spring Boot + SQLite 的单体应用，帮助野外生态研究者在**观测—自动打分—人工决定**三层分离的前提下，管理模糊观测的多身份假设，派生捕获历史，并产出仅用于方法验证的基础捕获概率摘要。

> 统计输出（捕获概率）**仅用于方法验证，不构成种群评估或生态管理建议**。

## 运行

需要 JDK 17+、Maven 3.9+。

```bash
# 构建（跳过测试）
mvn -q -DskipTests package

# 演示：先跑测试，再在 5337 端口启动
mvn -q test && mvn -q spring-boot:run -Dspring-boot.run.arguments=--server.port=5337
```

浏览器访问 <http://127.0.0.1:5337>。

SQLite 文件默认位于 `./data/wildlife.db`（首次启动自动建表并写入确定性种子数据），可用 `--idh.db.path=/path/to.db` 覆盖。

## 页面

- **观测时间线**：按调查时段分组，展示地点、时间、标记片段、花纹、观察者置信度，以及当前假设下的确认/否定/未决状态；零目击会话单独标注。
- **个体候选与特征对比**：每条观测保留全部自动候选（含“可能的新个体”），并排显示观测与个体的标记/花纹特征、原始分、冲突调整后分数与拒绝原因；可确认、登记新个体或否定。
- **时空冲突**：列出已确认归属中的 HARD 冲突；提供合并/拆分操作入口；汇总所有被降权（SOFT）或拒绝（HARD）的候选。
- **捕获历史**：`1/0/NA` 矩阵、每时段朴素捕获概率、统计口径与免责声明，可导出 CSV。
- **导入批次**：直接粘贴 JSON 批次重复提交，观察幂等行为。

## 核心概念与口径

### 1. 身份假设（Hypothesis）与版本

- 假设按**谱系（lineage）**组织：每个谱系至多有一个 `DRAFT`（草稿）和任意多个 `PUBLISHED`（已发布、不可变、带版本号）快照。
- **同一个已发布假设中，一条观测最多属于一个个体**（部分唯一索引保证）；未确认的观测保持未决。多个未决假设/谱系可以并存，互不覆盖。
- 草稿的每次修订都使 `revision` 加一；发布把草稿整体冻结为新版本快照（克隆当时的全部人工决定），随后同一谱系重开一个 `revision=0` 的新草稿。
- **数据分层保存，绝不覆盖**：
  - 原始观测：`observation`（永不删除；冲突只影响候选，不删观测）；
  - 自动得分：`candidate.raw_score / mark_component / pattern_component`（原始分永不被冲突调整覆盖）；
  - 人工决定：`hypothesis_assignment` 的 `CONFIRMED / DENIED / MERGED / SPLIT`，带 `reason_code` 与备注；
  - 审计：`hypothesis_change` 追加记录每次修订动作。
- 人工原因码：`MARK_LOST`（标记脱落）、`DUPLICATE_CODE`（重复编码）、`DATA_ENTRY_ERROR`（观察记录输入错误），以及 `OVERRIDE_CONFLICT / MERGE / SPLIT / NEW_INDIVIDUAL / AUTO_CARRIED / MANUAL_REVIEW`。
- **合并**是假设层面的决定：源个体的已确认观测改挂到目标个体，源个体仍保留在注册表（`original_individual` 留痕）。**拆分**把选定观测移到新个体或已存在个体，同样记录原身份。

### 2. 时间区间（显式时区、半开）

- 调查时段 `survey_period` 的端点存带偏移的 ISO-8601（种子用 `+09:00`），同时冗余 `*_epoch` 秒用于无歧义比较。
- 时段是**半开区间 `[start, end)`**：恰好在换班时刻的观测只属于后一期。种子中 `o-1007` 恰好发生在 `P1` 结束 / `P2` 开始的 `2026-03-20T08:00:00+09:00`，只归档到 `P2`（有测试断言）。

### 3. 缺失值：未观测 ≠ 观测为零

- `survey_session` 记录具体调查努力；`count_zero=1` 表示“**观察为零**”（有努力、无个体）。
- 一个时段没有任何会话表示“**未调查**”（缺失）。种子中 **P5 完全没有会话**。
- 捕获矩阵单元格：
  - `1`：该时段半开区间内有该个体的已确认非零观测；
  - `0`：该个体曾经出现过的地点在该时段有调查会话（含零目击会话），但没有捕获；
  - `NA`：该个体相关地点在该时段没有任何会话（缺失）。
- CSV 导出同时保留三类单元格与图例；整列 `NA` 的时段没有概率值（`NA`）。

### 4. 时空冲突

- 同一假设内，对某个体的拟确认会与其全部已确认锚点比较：72 小时窗口内按大圆距离/时间差估算平均移动速度；同时不同地直接视为冲突。
- 速度 `> 4 km/h` 为 **HARD**（候选调整分置零并 `REJECTED`；直接确认返回 422，研究者核对原始观测后可 `force=true` 强制覆盖，原因记为 `OVERRIDE_CONFLICT`，观测仍保留）；`> 2 km/h` 为 **SOFT**（分数减半并提示可疑）。阈值见 `HypothesisService` 常量。
- 种子中的 `o-1003`（北岭 10:05）与 `o-1004`（西坡 12:00，相距约 9.8 km / 约 5.1 km/h）构成 HARD：在候选视图中 I-001 被拒绝，但 `o-1004` 始终存在于时间线。

### 5. 自动打分

- 标记分量：片段对已知编码的**最佳滑窗 Levenshtein 相似度**（容忍部分编码/遮挡）。
- 花纹分量：花纹摘要的字符二元组 **Jaccard** 相似度。
- 综合分 `= (0.55*标记 + 0.45*花纹) * 观察者置信度`，裁剪到 [0,1]；当最佳已知匹配不够强时额外给出 `#NEW#`（可能的新个体）候选。
- 冲突调整只发生在**读取候选视图时**，按所选假设的已确认锚点实时计算；原始分保持不动。

### 6. 朴素捕获概率的统计口径

- 每时段 `p = 计数(1) / (计数(1) + 计数(0))`，**NA 单元格从分母中排除**；整时段全 NA  时概率为 `NA`（不报告）。
- 行只包含注册个体；未登记的 `#NEW#` 候选不进入统计。
- 这是方法验证用的**朴素检测比例**，未对检出异质性、闭合性、迁入迁出等建模，**不作生态管理建议**。

## 幂等与并发

- **导入批次幂等**：`import_batch.content_hash` 与 `observation(batch_ref, content_hash)` 唯一约束保证同一批次同内容重复提交不产生重复行（返回 `idempotentReplay`、`inserted=0`）。
- **发布幂等**：同一草稿同一 `revision` 重复发布返回同一已发布版本，不会生成 v2。
- **并发审阅（乐观锁）**：草稿的所有编辑都要求携带 `baseRevision`；过期提交得到 `409`，响应包含服务端当前 revision、客户端基础 revision、`retainYourChange=true` 以及自该 revision 以来对方的全部改动（`concurrentChanges`）。研究者据此 rebase 后重提，双方修改上下文都不丢失。

## 主要 HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/overview` | 地点/时段/会话/个体/假设与阈值 |
| GET | `/api/observations` | 全部观测 |
| POST | `/api/imports` | 幂等导入批次 |
| GET | `/api/observations/{id}/candidates?hypothesisId=` | 原始候选 + 冲突调整视图 |
| GET/POST | `/api/hypotheses` | 列表 / 新建草稿（可从快照克隆） |
| GET | `/api/hypotheses/{id}` | 假设详情、决定、审计、冲突 |
| POST | `/api/hypotheses/{id}/confirm` | 确认身份（可 `force` 覆盖 HARD） |
| POST | `/api/hypotheses/{id}/new-individual` | 登记并确认新个体 |
| POST | `/api/hypotheses/{id}/deny` | 否定候选（必须带原因码） |
| POST | `/api/hypotheses/{id}/split` / `/merge` | 拆分 / 合并 |
| POST | `/api/hypotheses/{id}/publish` | 冻结发布（幂等）并重开草稿 |
| GET | `/api/hypotheses/{id}/conflicts` | 当前 HARD 冲突 |
| GET | `/api/hypotheses/{id}/capture-history[.csv]` | 捕获矩阵、概率与 CSV |

## 测试数据（种子）

- 4 个地点（东/西/南/北岭相机）、5 个 10 天半开调查时段（P1–P5，`+09:00`）。
- 4 个已知个体、17 条 B1 批次观测：高分清晰匹配、多候选歧义（`o-1002`、`o-1003`）、不可达对（`o-1003`/`o-1004`）、换班边界（`o-1007`）、疑似新个体花纹（`o-1011`、`o-1014`）、模糊重影（`o-1016`）、3 条显式零目击；P5 无任何会话。
- 已发布快照 `H-SEED-v1`（9 条确认，其余保持未决）与克隆其决定的草稿 `H-WORK`（含一条 `DATA_ENTRY_ERROR` 人工否定，revision=1）。

测试 `WorkflowIntegrationTests` 覆盖：歧义多候选并存、不可达拒绝且观测保留、半开端点归档、`0` 与 `NA` 区分及 CSV、导入幂等、过期 revision 的 409 与 rebase、发布快照/幂等/不可变、否定原因码与原始分保留。
